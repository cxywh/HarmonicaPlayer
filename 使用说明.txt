Harmonica Player —— 游戏内口琴自动演奏工具
=============================================
版本 2.0.0

一、运行前
  1. 需要Windows 10或更高版本。
  2. 如果游戏是以管理员身份运行的，本程序也必须以管理员身份运行，
     否则系统会拦掉它发给游戏的按键。
     做法：打开程序 -> 设置 -> 勾选"以管理员身份运行" -> 点"立即以管理员身份重启"。

二、怎么用
  1. 双击HarmonicaPlayer.exe。
  2. 在主界面曲谱下拉框里选一首（songs文件夹自带14首）。
  3. 默认热键（设置里点"恢复默认"会回到这一套）：
        Num5  播放 / 开始        Num6  暂停 / 继续
        Num4  停止               Num0  重新播放
        方向键上  上一首         方向键下  下一首
     按上一首 / 下一首时，屏幕中央会浮出"当前歌曲：xxx"，几秒后自动消失。
  4. 热键都可以改：设置 -> 直接按下你想用的那个键。
     支持小键盘（Num0..Num9）、方向键、Insert / Home / End / PageUp / PageDown等。
     注意：小键盘的Num0只在NumLock打开时才是Num0，关掉时同一个键是Insert，
     想两种状态都能用就两个都绑。
  5. 演奏方式有6种：本音、左键（降八度）、中键（升半音）、右键（升八度），
     还有左键+中键、右键+中键两个组合（降八度升半音、升八度升半音，
     要同时按住两个鼠标键）。在"新建曲谱"里点按钮就能选。
  6. 新建曲谱的时值按钮按标准乐理：全音符到十六分音符，附点四分、附点八分，
     以及休止两拍 / 休止一拍 / 休止半拍（休止只占时间、不出声）。
     "延时"按钮把刚输入的那个音符再延长一拍。
  7. 演奏过程中按任意真实按键、鼠标键或鼠标滚轮 = 立刻急停并松开全部按键（安全机制）。
     游戏里常用的走动 / 跳跃键可以加进"设置 -> 排除键位"，避免误触发停止。
     排除键位里也能放单独一个修饰键：Ctrl、Shift、Alt、CapsLock、Tab 都可以，
     做法：点一下"排除键位"的输入框，直接按那个键。
     键位加错可以选中后删除。
  8. 键盘、鼠标键、鼠标移动、鼠标滚轮各有一项开关，可以单独关掉（滚轮默认关）。

三、文件说明
  HarmonicaPlayer.exe   主程序
  songs\                曲谱（JSON格式，可以自己加）
  settings.json         你的设置（第一次运行自动生成；删掉会回到默认值）
  debug.log             出错时的记录（遇到问题请把它发我）
