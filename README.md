# Harmonica Player

Windows 上的游戏内口琴自动演奏工具：按时间轴向当前窗口发送按键，让角色在游戏里自己吹口琴。
原生Win32 C++17（MSVC），单个exe，不依赖运行库。

## 下载

到 [Releases](https://github.com/cxywh/HarmonicaPlayer/releases) 下载
`HarmonicaPlayer-v2.0.0-win64.zip`，解压后双击 `HarmonicaPlayer.exe`
（内含主程序、14首曲谱、使用说明与声明）。

## 功能

- 精确时间轴播放：单调时钟（QPC），实测最大漂移0.235 ms
- 六种演奏方式：本音、左键（降八度）、中键（升半音）、右键（升八度），
  再加左键+中键、右键+中键两个组合键（降八度升半音、升八度升半音，同时按住两个鼠标键）
- 曲谱编辑支持标准时值：全音符到十六分音符，附点四分、附点八分，休止两拍/一拍/半拍；
  「延时」按钮可把刚输入的那个音符再延长一拍
- 全局热键：播放/暂停/停止/重播/上一首/下一首，都能改键
- 热键两种模式：**放行**（默认——不抢键，游戏照样收到那个键）与**独占**
- 切歌时屏幕中央浮出"当前歌曲：xxx"，几秒自动消失；不抢焦点、点击穿透
- 演奏中按真实按键、鼠标键或鼠标滚轮立即急停并松开全部按键；
  键盘/鼠标键/鼠标移动/鼠标滚轮各有一项开关（滚轮开关默认关），
  可设"排除键位"避免游戏内误停；排除键位里也能放单独一个修饰键（Ctrl、Shift、Alt、CapsLock、Tab）
- 曲谱为JSON格式并可内置编辑；`settings.json`存设置、`debug.log`记错误，两者误删会自动重建

## 运行要求

- Windows 10 及以上
- **游戏以管理员身份运行时，本程序也必须提权**（设置里勾选后会自动申请）
- 只模拟人手按键：不注入游戏进程、不读写游戏内存、不修改游戏文件

## 默认热键

| 按键 | 作用 | 按键 | 作用 |
|---|---|---|---|
| Num5 | 播放 / 开始 | Num6 | 暂停 / 继续 |
| Num4 | 停止 | Num0 | 重新播放 |
| 方向键上 | 上一首 | 方向键下 | 下一首 |

热键都能改（设置 -> 直接按你想用的键），支持小键盘、方向键、Insert、Home / End / PageUp / PageDown 等；
设置里点「恢复默认」会回到上面这套。

## 自己编译

```bat
build.bat        :: 主程序 + 10 个自检工具（输出到 dist\）
build.bat app    :: 只编主程序
```

需要 MSVC（Visual Studio 2022 / 2026 BuildTools）与 Windows SDK。

## 曲谱

`songs\` 下是 14 首 JSON 曲谱，可以直接加；`tools\jianpu2score.py` 是简谱转曲谱的脚本。
