# HarmonicaPlayer v2.0.0 发布说明

这一版从v1.0.0更新而来。装法没变：解压后双击HarmonicaPlayer.exe。

## 新增

- 演奏方式从4种增加到6种：本音、左键（降八度）、中键（升半音）、右键（升八度），
  再加左键+中键、右键+中键两个组合键。组合键要同时按住两个鼠标键，
  用来吹"降八度升半音"和"升八度升半音"这两组音。
- 新建曲谱支持标准乐理时值：全音符、二分音符、四分音符、八分音符、十六分音符，
  附点四分、附点八分，以及休止两拍、休止一拍、休止半拍。休止只占时间、不出声。
- 鼠标滚轮也能打断演奏，默认开启。游戏里走动、跳跃一般用不到滚轮，误触少。
- 新增两首曲谱：《父亲》《世上只有妈妈好》。自带曲谱一共14首。

## 修复

- 用带鼠标键的演奏方式（左键/中键/右键/组合键）时，演奏结束后鼠标键可能一直处于按下的状态，
  得自己再点一下才松开。这一版演奏结束会正常抬起。
- 时值按钮的文字能完整显示，不再被截断。
- 放行模式下打游戏时，正常的按键不再被记成错误写进debug.log。

## 已知

  在设置里勾选"以管理员身份运行"后点"立即以管理员身份重启"。
